# Sprout Points PWA Instructions

## Launch URL

Open the app at:

https://ashwiniashokshamayatech.github.io/sprout-points/

The repository must be public and GitHub Pages must be enabled for the `main` branch before this URL will work.

## Install on Android

1. Open the URL in Chrome.
2. Open the three-dot menu.
3. Select **Install app** or **Add to Home screen**.
4. Confirm the installation.

## Install on iPhone or iPad

1. Open the URL in Safari.
2. Tap the **Share** button.
3. Select **Add to Home Screen**.
4. Tap **Add**.

## Install on Desktop

1. Open the URL in Chrome or Edge.
2. Select the install icon in the address bar, or open the browser menu.
3. Choose **Install Sprout Points**.

## Backup and Restore

The app saves data locally in the browser on each device. It does not automatically synchronize data between devices.

To create a backup:

1. Open **Backup**.
2. Select **Download backup**.
3. Keep the downloaded JSON file somewhere private and safe.

To move data to another device:

1. Open the app on the other device.
2. Open **Backup**.
3. Select **Choose backup file**.
4. Select the downloaded JSON file.
5. Confirm **Restore backup**.

Restoring replaces the data currently saved on that device. Backup files may contain child names, points, notes, and history, so do not share them publicly.
